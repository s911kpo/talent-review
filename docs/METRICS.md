# 儀表板指標字典

每個指標在畫面上都有 (i) 按鈕，內容與本文件一致。原則：**不評分、不排名、不設比例目標**。可以比較部門與職位，不比較個人。

儀表板分成六頁，每頁回答一個管理問題：

| 頁面 | 回答的問題 | 誰看得到 |
|---|---|---|
| 總覽 | 現在最需要注意的三件事是什麼？哪個部門最需要關注？ | HR、Supervisor（自己的範圍） |
| 組織畫像 | 關鍵人才在哪裡、是什麼樣的人？ | 同上 |
| 留任風險 | 誰可能離開、為什麼、誰離開影響最大？ | 同上 |
| 接班梯隊 | 關鍵職位明天空出來，有人接嗎？ | 同上；「被重複倚重的接班人」只有 HR |
| 職涯與發展 | 人才往哪裡走？發展計畫是否落實？ | 同上 |
| 行動清單 | 這個月該找誰談？ | 只有 HR |

## 引導提問

每張圖右上角的「引導提問」有三個問題，依序是「看懂現況 → 找出原因 → 決定行動」，給第一次參與盤點的主管與 HRBP 在討論時使用。個人檔案最上方的「對話準備」則依該員工被填寫的內容（是否談過職涯、流失原因、下一步準備度、是否缺接班人、流動意願、發展計畫）挑出最多 4 個問題。這些是可以問的問題，不是對人的結論。題目內容在 `src/i18n/dash.*.json` 的 `probe` 與 `person`。

## 總覽：五個核心指標

| 指標 | 定義 | 計算方式 | 管理上怎麼用 |
|---|---|---|---|
| 盤點完成率 | 已經提交給 HR 的關鍵人才盤點 | 已提交以後（含已確認、已鎖定）÷ 全部關鍵人才 | 進度落後時看「首頁」的團隊清單。其他指標在完成率高時才具代表性 |
| 關鍵人才 | Supervisor 勾選為關鍵人才的人 | 人數；佔比 ＝ 關鍵人才 ÷ 盤點範圍人數 | 佔比只是參考、不是目標。用來檢查各部門的提名標準是否一致 |
| 留任警示 | 坐在關鍵職位、且被評為高流失風險的人 | 關鍵職位 ＝ 是，且流失風險 ＝ 高 | 一旦離開業務立刻受影響。兩週內由 Supervisor 與 HRBP 擬定個別留任行動 |
| 接班就緒率 | 至少有一位「可立即接任」接班人的關鍵職位比例 | 有已就緒接班人的關鍵職位 ÷ 全部關鍵職位（TBH 不算） | 偏低代表職位空出時多半要外部招募或長期空缺 |
| 職涯對話缺口 | 勾選「尚未與本人討論職涯期望」的關鍵人才 | 勾選人數 ÷ 全部關鍵人才 | 職涯對話是成本最低的留才行動，中高風險者優先 |

### 本期重點（自動產生）
系統依目前篩選範圍，依固定順序最多列出三句話：
1. **風險熱點**：關鍵人才 ≥5 人的部門中，中高流失風險比例最高、且比整體高 15 個百分點以上的部門。
2. **接班缺口**：兩年內沒有人能接手的關鍵職位數。
3. **重複倚重的接班人**（只有 HR）：被列為 3 個以上職位接班人的人。
4. **對話缺口**：中高風險、但還沒談過職涯的人數。

### 部門人才健康度
每個部門並排四個值：關鍵人才數、中高流失風險比例、接班就緒率、職涯對話缺口。表格第一列是整體，條上的黑色刻度是整體值。
**「需注意」**：比整體差 10 個百分點以上（風險、對話缺口是高於；就緒率是低於），且該部門有 3 位以上相關人員。部門是比較對象，不是評比 Supervisor。

## 組織畫像

| 指標 | 計算方式 | 怎麼用 |
|---|---|---|
| 部門人數與關鍵人才 | 深色 ＝ 關鍵人才，淺色 ＝ 其他範圍內人員；比例 ＝ 關鍵人才 ÷ 範圍人數 | 看關鍵人才是否集中在少數部門 |
| 女性人才管道 | 盤點範圍 → 關鍵人才 → 關鍵職位 → 已就緒，每一步的女性人數 ÷ 該步人數；少於 5 人不顯示。右側各部門：灰點 ＝ 範圍、紫點 ＝ 關鍵人才 | 找出比例下降最多的一步（標紅），那一步就是要檢視提名、任用或發展機會的地方 |
| 年資結構 | 直立柱狀：各年資區間人數 ÷ 該群體人數（關鍵人才 vs 整體）；上方標示 5 年以上與未滿 1 年的比例 | 集中資深：傳承與退休風險；集中資淺：培養期長 |
| 為什麼是關鍵人才 | 每個理由被選的人數 ÷ 關鍵人才（可複選） | 反映組織真正依賴的能力；「稀缺技能」多代表傳承風險 |

## 留任風險

| 指標 | 計算方式 | 怎麼用 |
|---|---|---|
| 留任風險地圖 | 流失風險（高中低）× 是否關鍵職位，六格人數；格內百分比 ＝ 佔關鍵人才 | 先處理「高 × 關鍵職位」 |
| 主要流失原因 | 每個原因被勾選的人數 ÷ 中高風險人數（可複選） | 原因集中時用制度面一次處理 |
| 中高風險且未談職涯 | 流失風險中或高，且勾選「尚未討論」 | 兩週內安排 15 分鐘對話 |
| 最可能被挖角 | 流失風險高，且下一職位準備度為「已就緒」 | 優先討論晉升、輪調或擴大職責 |

## 接班梯隊

每個關鍵職位依「最佳接班人」的準備度分四類：

| 類別 | 條件 |
|---|---|
| 已就緒（綠） | 有可立即接任的接班人 |
| 1–2 年（藍） | 最佳接班人 1–2 年內可接 |
| 長期（黃） | 只有 3 年以上或緊急代理 |
| 無人（紅） | 沒有接班人，或只有待招募（TBH） |

| 指標 | 計算方式 | 怎麼用 |
|---|---|---|
| 各部門接班梯隊 | 每部門關鍵職位依上表分類，條長 ＝ 關鍵職位數 | 黃＋紅 ＝ 兩年內的接班缺口 |
| 接班缺口 | 關鍵職位，且最佳接班人為長期或無人 | 優先指定接班人或提早規劃招募 |
| 關鍵職位風險矩陣 | 橫軸：任職者流失風險（高、中、低）；縱軸：最佳接班人（無人、長期、1–2 年、已就緒）。只有危險區上色（深紅：高風險且無人；淺紅：中風險且無人、高風險且只有長期人選） | 右側列出危險區的職位，從深紅開始處理。比較的是職位，不是人 |
| 接班深度 | 每個關鍵職位列出的人選數（內部或外部，不含 TBH）：0、1、2 位以上 | 只有 1 位人選很脆弱；一線做法是關鍵職位至少 2 位 |
| 被重複倚重的接班人（HR） | 同一人被列為 2 個以上職位的接班人 | 一人只能接一個位子，實際覆蓋比帳面低 |
| 外部依賴度 | 外部人選與 TBH ÷ 所有接班人選 | 越高越依賴外部招募 |
| 紙上接班 | 近期接班人（已就緒或 1–2 年）本身是中高流失風險 | 留住接班人等於保住兩個職位 |

## 職涯與發展

| 指標 | 計算方式 | 怎麼用 |
|---|---|---|
| 下一步準備度 | 每人取多個下一職位中最近的準備度，各準備度人數 | 已就緒卻沒機會的人，流失風險會上升 |
| 流動意願 | 各選項人數 | 近期願意流動的人，是內部補缺第一順位 |
| 內部可調動人才庫 | 流動意願為現在或 1–2 年，且下一職位準備度為已就緒或 1–2 年 | 開缺時先從這份名單找 |
| 發展計畫執行狀態 | 各狀態的目標數（未開始、進行中、有風險、已完成），以及擁有該狀態目標的人數 | 「有風險」「未開始」要在下一次檢核點前找出原因 |
| 70/20/10 發展組合 | 各類型行動數 ÷ 有填類型的行動數，對照參考比例 | 上課比例偏高 ＝ 缺少實戰任務。參考不是目標 |
| 發展計畫完整率 | 計畫必填欄位都完成的關鍵人才 ÷ 全部關鍵人才 | 不完整就無法追蹤 |
| 檢核點月曆 | 依目標日期的月份計數；最高的月份標深色 | 高峰前一個月提醒 Supervisor |
| PBM 核心價值 | 每項 Our Values 被列為強項、改善機會的次數 | 多數人共同的改善項，適合團體課程 |

## 行動清單（只有 HR）

| 行動 | 條件 | 建議行動 | 負責 |
|---|---|---|---|
| 先找這些人聊職涯 | 中高風險且未談職涯 | 兩週內 15 分鐘對話 | Supervisor |
| 補強紙上接班 | 見「紙上接班」 | 接班人列入留任行動或補第二人選 | Supervisor ＋ HRBP |
| 確認被忽略的潛力 | 被其他 Supervisor 列為已就緒或 1–2 年的接班人，但自己不是關鍵人才 | 校準會議確認是否補列 | HRBP |
| 留才但沒有發展計畫 | 中高流失風險，但發展計畫不完整 | 把留任對話的結果寫進發展計畫 | Supervisor |
| 開缺前先看內部 | 接班薄弱的關鍵職位，對應到「下一步就是這個職稱」且近期可就緒的人（職稱文字比對） | 招募前先談 | HRBP ＋ 招募 |
| 校準時多問一句 | 4 位以上關鍵人才的團隊出現：全部低風險、準備度全部相同、評核方式過於簡略、全部已就緒且無 TBH | HRBP 確認填寫依據 | HRBP |

## 拿掉的項目與原因

| 原本的項目 | 處理 | 原因 |
|---|---|---|
| 部門 treemap、部門指標熱力表（7 欄） | 改為「部門人數與關鍵人才」長條圖與「部門人才健康度」（4 個核心指標＋需注意標示） | 面積與色階難以判讀，7 欄沒有重點 |
| 性別組成文字清單 | 改為「女性人才管道」 | 文字密度過高；人形圖示仍不易一眼看出重點 |
| 單點失效清單 | 改名「接班缺口」，依部門彙總 | 名稱不直覺；長名單沒有重點 |
| 接班網絡（sankey） | 改為「關鍵職位接班地圖」，再改為「關鍵職位風險矩陣」 | 線太多無法閱讀；方塊地圖顏色太多抓不到重點 |
| 期望地點 | 移除，保留在個人卡片 | 自由填寫的文字無法收斂成管理訊息 |
| 負責人負荷（行動數） | 移除 | 業界不使用，沒有管理意義 |
| 各評核人完成度 | 移到 HR 首頁的「各團隊進度」 | 是進度追蹤，不是人才分析 |
| 管理洞察（六個文字面板） | 改為「行動清單」：每項一個數字、為什麼、建議行動、負責人 | 原本只是列名單，沒有收斂成行動 |
| 內部流動供給 vs 外部招募表 | 移除 | 與「開缺前先看內部」重複 |
| 頂部 KPI 中的 TBH 職位數 | 併入接班梯隊（「無人」類別） | 總覽只留五個最核心的數字 |

## 高管戰情頁（/hr/exec）

使用與上面相同的指標，依「全貌 → 留任風險 → 接班梯隊 → 發展與流動 → 請管理層決定」排列。新增的組合只有兩個：

| 指標 | 計算方式 |
|---|---|
| 部門熱度 | 部門 × 三個比例（中高流失風險、接班就緒率、職涯對話缺口）；比全廠差 10 個百分點以上且 3 人以上才上色。程式：`src/lib/metrics/exec.ts` 的 `attentionSignals` |
| 危險區職位 | 關鍵職位風險矩陣中的「高風險且無人」「中風險且無人」「高風險且只有長期人選」。程式：`dangerRoles` |
