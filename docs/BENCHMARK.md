# 對標一線 HR 系統：已做與建議

2026-11-12。對標對象：Workday Talent & Performance、SAP SuccessFactors Succession & Development、Cornerstone、Lattice、Culture Amp。
限制不變：只用原本 Excel 範本的欄位；不做九宮格、不排名、不設比例目標（SPEC §0）。

## 一、為什麼要加「引導提問」

這是新店廠第一次做人才盤點，主管不熟悉流程，也還不清楚盤點結果之後要怎麼用。一線系統的做法是：**每個數字旁邊都告訴主管「接下來要問什麼」**，把報表變成對話的起點，而不是終點。

這次加了兩層：
1. **指標層**：每張圖右上角的「引導提問」，三個問題依序是「看懂現況 → 找出原因 → 決定行動」。例如「留任警示」：最近一次談職涯是什麼時候？→ 如果他下個月離開，哪些工作會停擺？→ 我們能給他什麼留下來的理由？
2. **個人層**：點進任何一個人，最上方是「對話準備」，依 Supervisor 填的內容自動挑出最多 4 個問題。例如勾了「薪酬因素」，就出現「你覺得目前的回報和你的貢獻相符嗎？最在意哪一部分？」。這些是可以問的問題，不是對人的結論。

管理意義：人才發展不是盤點完成的那一刻發生的，而是在盤點後的每一次對話裡發生的。系統要做的是讓第一次做盤點的主管也知道「下一句話該怎麼開口」。

## 二、這次已經做進系統

| 一線系統的做法 | 這次的對應 | 解決的問題 |
|---|---|---|
| 報表下鑽後可以一路追下去再原路返回（Workday drill path、SuccessFactors breadcrumbs） | 名單 → 個人檔案 → 他的接班人 → 再下一層，頂部有麵包屑與「返回」 | 原本只能看名單，點進去就斷了 |
| 瀏覽器「上一頁」可以回到剛才的分析 | 分頁、篩選、HR 後台頁面都寫進網址 | 原本按上一頁會整個離開後台 |
| 從部門點進去後有明確的「回到全廠」 | 部門篩選時頂部出現「← 回到全廠」 | 篩選後不知道自己在看哪一層 |
| 摘要卡可直接跳到分析頁（SuccessFactors tile → detail） | KPI 卡下方「查看分析 →」 | 看到數字後不知道去哪裡找原因 |
| 人才檔案（Workday talent card） | 個人檔案：為什麼是關鍵人才、風險與原因、下一步、流動、接班人、發展計畫、被誰列為接班人 | 原本要展開整份表單才看得到 |
| 接班風險：任職者流失風險 × 接班準備度（SuccessFactors risk of loss） | 關鍵職位風險矩陣，只有危險區上色，右側列出最需要先處理的職位 | 原本的方塊地圖顏色太多，抓不到重點 |
| 接班深度（bench depth） | 每個關鍵職位有 0、1、2 位以上人選 | 只看「有沒有接班人」會高估覆蓋 |
| 人才庫（talent pool） | 內部可調動人才庫：兩年內準備好、也願意流動 | 開缺時不知道內部先找誰 |
| 發展計畫執行追蹤 | 發展計畫執行狀態（未開始、進行中、有風險、已完成） | 盤點後沒有人看計畫有沒有在動 |
| 多元性管道（leaky pipeline） | 女性人才管道：範圍 → 關鍵人才 → 關鍵職位 → 已就緒，標出落差最大的一步 | 原本只看比例，看不出問題在哪一步 |

## 三、建議下一步（需要 Tim 決定）

依管理價值排序。都只用現有欄位。

1. **校準會議模式**（Workday Talent Review calibration）
   HRBP 與上一級 Supervisor 開討論會時，用一個畫面依團隊逐人檢視：風險、準備度、接班人、引導提問，並可直接記下會議結論與後續行動。不做強制分配，只校準「描述是否一致」。這是把盤點變成真正管理對話的關鍵一步。約 1 天。
2. **接班組織圖**（SuccessFactors succession org chart）
   以組織架構呈現每個關鍵職位：任職者、風險、接班人與準備度。主管最熟悉組織圖，比表格更直覺。約 1 天。
3. **個人一頁式檔案匯出（PDF）**
   討論會前列印或寄給上一級 Supervisor。約半天。
4. **離職衝擊模擬**（上次提過）
   選一個人，看他離開會影響哪些關鍵職位（他本人的、以及他被列為接班人的）。約半天。
5. **發展計畫季度檢核提醒**（SPEC §15 已預留）
   檢核點到期前一個月自動提醒 Supervisor，HR 看完成率。需要新增排程。約 1 天。
6. **跨週期趨勢**（第二次盤點後）
   同一人、同一部門的風險、準備度、接班深度變化。證明盤點價值最有力的證據。

## 四、刻意不做的

- 九宮格、績效 × 潛力矩陣、任何排名或配額（SPEC §0）。「關鍵職位風險矩陣」比較的是職位的接班風險，不是人的表現。
- 把「校準提示」「被其他 Supervisor 看見的人才」開放給 Supervisor：涉及主管之間的比較，只給 HR。
